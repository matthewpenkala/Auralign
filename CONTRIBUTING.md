# Contributing To Auralign

Auralign does not accept unsolicited code, documentation, model, dataset, or
other content contributions. Do not open a pull request or send a patch unless
Matthew Penkala has invited the work and confirmed that the required agreement
is fully executed.

## Before Contributing

An invited contributor must execute, outside this repository, a counsel-reviewed
confidentiality and contributor/IP agreement covering at least:

- authority to contribute and return modifications of PolyForm-licensed source;
- copyright and patent grants, including sufficient sublicensing/relicensing
  authority for the project owner;
- employer, client, contractor, and prior-agreement authorization;
- third-party source provenance and preservation of all required notices;
- confidential-information exclusions and repository confidentiality;
- disclosure and human review of AI-assisted material.

No DCO sign-off, Git commit, click-through, pull-request checkbox, issue comment,
or repository role substitutes for the executed agreement. This file is policy,
not the contributor agreement. The project does not adopt DCO 1.1 because its
[official certification](https://developercertificate.org/) is written for
open-source contribution workflows and does not supply Auralign's required
confidentiality or contributor/IP terms.

## Invited Workflow

After written confirmation that the agreement is effective:

1. read `AGENTS.md` and [`docs/legal/README.md`](docs/legal/README.md);
2. work only within the approved scope and preserve license/provenance notices;
3. record every third-party source and update dependency/external-asset records;
4. keep private source and sensitive runtime data in approved systems only;
5. complete the pull-request provenance, licensing, privacy, and artifact checks;
6. obtain CODEOWNERS review before merge.

Contributions are accepted only when the owner merges them. Submission does not
guarantee acceptance and does not alter Auralign's controlling license.
