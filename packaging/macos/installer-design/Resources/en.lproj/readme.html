This package installs two mandatory, independently versioned components:

  • Auralign 0.3.1 in /Applications.
  • Offline bootstrap resources 2.0.0—Community-1 diarization, English alignment, ECAPA speaker support, and deterministic Punkt—in the system Application Support folder.

Recipients do not need Xcode, Command Line Tools, Python, Homebrew, Git, a source checkout, a virtual environment, a Hugging Face account, or Terminal. The package does not run network scripts. On first launch, choose Complete Offline Setup to install one exact public ASR pack through the signed app. This needs a connection unless the pack is already installed or imported, but no token. Processing is local and offline afterward. Results, settings, packs, caches, and logs remain in the current user's Library.
