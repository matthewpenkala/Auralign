Speech-recognition packs after installation

Auralign's signed native model manager can install one of sixteen exact public MIT-licensed CTranslate2 or MLX Whisper packs after installation. These packs are not Installer payloads and no Installer script downloads them. The app uses pinned revision URLs, verifies every path, size, SHA-256, license, notice, provenance, CycloneDX SBOM, and completion record, and publishes only a complete verified pack in the current user's Application Support folder.

The public pack flow requires a connection unless the exact pack is already installed or imported, but it requires no Hugging Face account, token, Terminal, Python, package manager, or developer tools. Each pack carries the complete MIT text, attribution, notices, and exact immutable identity. Normal transcription is local and offline only after the selected pack verifies.
