The repository classifies tracked paths as follows:

| Path class | Provenance disposition |
| --- | --- |
| `src/`, `tests/`, `docs/`, `examples/`, scripts, configuration, and workflows | Auralign-first-party unless a more specific in-file or registry record applies |
| `macos/` Swift source, project metadata, and Auralign-owned application assets | Auralign-first-party unless the adjacent asset record or a more specific notice applies |
| `packaging/` PKG definitions and first-party Installer presentation assets | Auralign-first-party integration; exact imported first-party asset lineage and modifications are recorded in `macos/ASSET_PROVENANCE.md` |

| Declared Python packages and build tools | Referenced, not vendored into the source tree; governed by upstream terms |
| Models, datasets, media, caches, profiles, and run output | External/private material; excluded from source and general archives. The 0.3.1 exception is the exact three-model bootstrap v2 inside the private product PKG plus sixteen exact native-download ASR packs; raw caches and loose model assets remain prohibited |

asset registry together form the path and component rights ledger. A more
specific upstream notice always overrides the first-party default.

## Private macOS 0.3.0 Model Delivery Decision

On 2026-07-25, Matthew Penkala recorded the project decision for all nineteen
exact model entries in the private macOS 0.3.0 product. This is a release-scope
and provenance record, not legal advice, a legal opinion, a claim that Auralign
owns those assets, or a change to upstream terms.

The product PKG's root-owned
`com.auralign.studio.models.bootstrap.v1` version `1.0.0` component contains
only exact `community-1`, `en`, and `ecapa` files plus deterministic
corpus-free Punkt. The sixteen CTranslate2/MLX ASR choices are exact per-user
native-download packs because their bytes cannot fit the private release host's
per-asset limit. Every pack has an immutable revision, file/size/SHA-256
contract, license/attribution, versioned pack ID, deterministic notices,
provenance, CycloneDX SBOM, and completion record.

Normal presets map to `max=large-v3`, `balanced=turbo`,
`fast=distil-large-v3.5`, and `cpu=turbo`; `distil-large-v3` and all twelve
MLX entries are optional advanced selections. Every visible entry has real
local backend evidence and an exact delivery path. Presence in source alone
would not prove this; the external-asset registry and accepted artifact
evidence do.

Neither the PKG nor native packs may include raw caches, tokens, private
linkage markers, acquisition histories, or local paths. Model bytes never enter
Git or appear as loose release assets. Public ASR packs are downloaded by the
signed app from revision-bound catalog URLs, staged privately, verified
completely, and published atomically without Installer scripts or credentials.

For Community-1, the pinned official model card and repository API identify
CC-BY-4.0 and an automatic contact/acquisition gate; the pinned file listing has
no standalone `LICENSE`. The recorded disposition follows that official
evidence while preserving attribution and the separate privacy, voice,
training-data, and downstream-use caveats. If later evidence conflicts, the
model component and release fail closed pending a new human review.

## `Adapt whispermlx pipeline improvements`

The pre-publication change titled `Adapt whispermlx pipeline improvements`
changed Auralign's MLX, alignment, diarization, export, configuration, and test
implementation. The recorded review compared Auralign against
[`KalebJS/whispermlx`](https://github.com/KalebJS/whispermlx) at upstream commit
`37816743c29a569405f300bbb4b3ef8001152651` (tag `v3.12.2`) using a shallow,
read-only checkout. The review
inspected the upstream README, package metadata, ASR, transcription,
diarization, VAD, alignment, subtitle, schema, utility, and related test files,
then compared the relevant Auralign modules and tests.

The technical review disposition is **concepts and public interfaces only**.
Auralign
implemented local model-alias ergonomics, opt-in VAD-windowed ASR, progress and
alignment diagnostics, conservative speaker assignment, and subtitle behavior
within its existing architecture. The implementation record explicitly states
that WhisperMLX source was not copied and rejects upstream auto-download,
token-driven setup, and runtime-download behavior. No copied, translated,
patched, or AI-transformed WhisperMLX source was identified by the recorded
technical comparison.

WhisperX is a separately declared optional dependency, currently pinned by the
lock and component registry at version `3.8.6` under BSD-2-Clause. The relevant
pre-publication adaptation changed only Auralign diagnostic fields around its
pre-existing calls to documented WhisperX public APIs; it did not introduce a
WhisperX source copy. This is a repository provenance determination, not a
waiver of upstream terms. The private history bundle and development record
preserve the comparison evidence, subject to the owner's chain-of-title
confirmation above.

If later evidence contradicts this determination, publication fails closed:
